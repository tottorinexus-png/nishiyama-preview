【お問い合わせフォームの設定】
contact.html の form 要素にある data-endpoint="" に、
Formspree等で発行した送信先URLを設定してください。
例：
<form id="contact-form" data-endpoint="https://formspree.io/f/xxxxxxxx">

未設定の状態では、入力内容をクリップボードへコピーする提案用動作になります。

【GitHub Pages】
このフォルダ内のファイルと assets フォルダを、そのままリポジトリ直下へアップロードしてください。
index.html がトップページとして表示されます。

チラシから確認できた情報を基礎にしていますが、日程・料金等の変動情報は掲載していません。
実際に公開する前に、必ず西山先生へ全掲載内容の確認を取ってください。


【2024年度夏期授業チラシの反映】
ユーザー提供の2024年度夏期授業募集チラシを根拠に、次の内容を反映しました。
・期間：2024年7月20日（土）〜8月17日（土）
・対象：小学生・中学生
・内容：これまでに習ったことの復習
・小学生・標準：小2〜小6、50分×8回、国語か算数、8,800円
・中学生・標準：中1、50分×16回、数学・英語、15,400円
・中学生・標準：中2、50分×16回、国語・理科、15,400円
・中学生・受験：中3、50分×24回、国語・英語・理科、22,000円
・別途教材費：1教科550円
・表中以外の教科や学習方法も相談可能

これらは「2024年度の過去実施例」と明記しています。
現在の募集内容として公開する場合は、西山先生へ最新情報を確認して差し替えてください。
